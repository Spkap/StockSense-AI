StockSense Conviction Desk

A thesis-first investment research system that persists user beliefs, collects evidence, challenges claims, and returns a conviction diff with auditable receipts.

Business Context

User

Self-directed investor

Tracks a small portfolio or watchlist and wants to know whether the original thesis is still valid.

Workflow

Belief update loop

Create thesis, decompose claims, check evidence, inspect receipts, correct the system, monitor changes.

Differentiator

Conviction diff

The output is not buy/sell. It is what strengthened, weakened, broke, or remains unsupported.

Data Flow

Processing Pipeline

Step 1

Thesis Graph

Claims, assumptions, metrics, horizon, kill criteria.

Step 2

Evidence Bundle

Parallel source collection with freshness and failure states.

Step 3

Adversarial Check

Challenge claims using only provided evidence IDs.

Step 4

Conviction Diff

Return verdict, claim changes, receipts, and next actions.
